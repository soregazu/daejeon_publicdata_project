# daejeon_publicdata_project

# PRD: 대전 맞춤형 주거적합도 AI 서비스

## 1. 제품 개요

### 제품명
대전 맞춤형 주거적합도 AI

### 한 줄 설명
사용자의 예산, 생활패턴, 이동 조건, 안전/편의 선호를 바탕으로 대전 내 살기 좋은 주거지와 매물 후보를 추천하고, 추천 이유를 설명하는 공공데이터 기반 AI 주거 의사결정 보조 서비스.

### 핵심 가치
기존 부동산 플랫폼이 매물 정보를 나열하는 데 집중한다면, 본 서비스는 사용자의 실제 삶의 조건에 맞춰 “어디에 살아야 후회가 적은지”를 판단할 수 있도록 돕는다. 집 내부 조건뿐 아니라 주변 환경, 교통, 생활SOC, 안전, 개발/정비 흐름 등 외부 조건을 함께 반영해 소비자 관점의 주거 선택을 지원한다.

## 2. 문제 정의

### 배경
대전은 도안 신도시, 갑천지구, 대전역세권, 원도심 재개발 등 주거환경 변화가 활발한 지역이다. 그러나 일반 사용자는 특정 동네나 매물이 실제로 살기 좋은지 판단하기 어렵다. 월세, 보증금, 면적 같은 내부 조건은 비교하기 쉽지만, 통근 편의성, 생활SOC 접근성, 치안, 소음, 개발 호재, 실거래가 안정성 등 외부 조건은 여러 데이터를 따로 확인해야 한다.

### 사용자 문제
- 매물은 많지만 내 조건에 맞는 주거지를 고르기 어렵다.
- 부동산 플랫폼은 매물을 보여주지만, 사용자 입장에서 좋은 선택인지 설명하지 않는다.
- 대전의 신도시 개발, 원도심 정비, 역세권 개발 같은 지역 변화가 주거 선택에 어떤 의미를 갖는지 알기 어렵다.
- 청년, 신혼부부, 대학원생, 이주 직장인 등은 지역 정보 비대칭으로 인해 불리한 선택을 할 가능성이 높다.

### 해결하고자 하는 질문
“내 예산과 생활조건을 기준으로 대전에서 어디가 가장 살기 좋은가?”

## 3. 목표

### 제품 목표
- 사용자 조건에 맞는 대전 내 추천 주거지역 또는 매물 후보를 제시한다.
- 추천 결과에 대해 데이터 기반의 명확한 이유를 설명한다.
- 공공데이터를 활용해 주거비, 생활환경, 교통, 안전, 개발/정비 정보를 종합 평가한다.
- 기존 부동산 중개 플랫폼과 달리 소비자 중심의 주거 의사결정 도구를 제공한다.

### 경진대회 목표
- 공공데이터 활용성 30점 영역에서 높은 점수를 확보한다.
- AI가 서비스의 핵심 의사결정과 설명 기능을 담당하도록 설계한다.
- 추천 성능과 사용자 만족도를 검증할 수 있는 MVP를 제시한다.
- 대전 지역 문제와 연결된 사회적 가치와 사업 확장 가능성을 보여준다.

## 5. 서비스 범위

### MVP 범위
MVP는 “실시간 모든 매물 추천”이 아니라 “대전 내 주거 후보지/생활권 추천 + 사용자가 입력한 매물 조건 평가”를 우선 목표로 한다.

### MVP 핵심 기능
- 사용자 조건 입력
- 대전 주거적합도 점수 산출
- 추천 동네 또는 후보 지역 TOP 5 제공
- 추천 이유와 주의점 설명
- 지도 기반 시각화
- 유사 대안 지역 제시
- 사용자가 직접 입력한 매물의 적합도 평가

### 향후 확장 기능
- 부동산 플랫폼 매물 URL 분석
- 제휴 매물 데이터 연동
- 주거 지원 정책 추천
- 신혼부부/청년/고령자 맞춤 모드
- 개발 호재 및 정비사업 리스크 알림
- 월세 변동 예측 및 거주 안정성 분석

## 6. 핵심 사용자 흐름

### 기본 흐름
1. 사용자가 예산, 직장/학교 위치, 생활 선호, 차량 보유 여부, 가족 구성, 중요 요소를 입력한다.
2. 서비스가 공공데이터 기반 주거지표와 사용자 가중치를 결합한다.
3. AI가 대전 내 추천 후보 지역을 산출한다.
4. 사용자는 추천 지역 TOP 5와 각 지역의 장단점을 확인한다.
5. 사용자는 특정 매물 정보를 입력하거나 비교 후보를 선택한다.
6. AI가 “이 사용자에게 이 집이 적합한 이유/부적합한 이유”를 설명한다.

### 입력 항목
- 월세/전세/매매 여부
- 보증금, 월세 또는 전세금 상한
- 직장/학교 위치
- 희망 통근 시간
- 차량 보유 여부
- 가족 구성
- 선호 생활권
- 중요도 가중치: 교통, 안전, 편의시설, 조용함, 저렴함, 개발 가능성, 교육, 공원/녹지
- 회피 조건: 유흥가 인접, 소음, 언덕, 대중교통 불편, 치안 취약 등

### 출력 항목
- 추천 지역 TOP 5
- 지역별 종합 주거적합도 점수
- 사용자 맞춤 추천 이유
- 주의해야 할 조건
- 공공데이터 기반 근거
- 비슷한 대안 지역
- 입력 매물의 적합/주의/비추천 판단

## 7. 데이터 활용 계획

### 공공데이터
- 국토교통부 전월세 실거래가 데이터
- 국토교통부 또는 공공데이터포털 주택/건축물 관련 데이터
- 대전광역시 생활SOC 및 공공시설 데이터
- 대전광역시 교통 관련 데이터: 지하철역, 버스정류장, 환승 접근성
- 대전광역시 도시정비사업, 재개발/재건축, 도시개발사업 현황
- 경찰청 또는 공공데이터포털 안전/범죄 관련 통계
- 행정안전부 인구, 세대, 생활안전 관련 데이터
- 교육시설, 의료시설, 공원, 문화시설, 체육시설 위치 데이터

### 민간 또는 사용자 입력 데이터
- 사용자가 직접 입력한 매물 정보
- 향후 제휴 또는 크롤링 허용 범위 내 매물 데이터
- 사용자의 추천 만족도 피드백

### 주요 파생 지표
- 환산월세: 월세 + 보증금 환산액
- 단위면적당 주거비
- 대중교통 접근성 점수
- 생활SOC 접근성 점수
- 안전 점수
- 교육/보육 접근성 점수
- 의료/편의시설 접근성 점수
- 녹지/공원 접근성 점수
- 개발/정비 영향 점수
- 거주 안정성 점수
- 사용자 맞춤 종합 주거적합도 점수

## 8. AI 기술 설계

### AI의 핵심 역할
AI는 단순 부가 기능이 아니라 서비스의 핵심 판단과 설명을 담당한다.

### 주요 AI 기능
- 사용자 프로필 기반 선호 가중치 추론
- 지역/매물별 주거적합도 예측
- 유사 사용자 기반 추천
- 추천 결과의 자연어 설명
- 사용자의 추가 질문에 답변하는 주거 상담형 챗봇
- 특정 매물의 장단점 요약

### 추천 모델 구조
1. 규칙 기반 필터링: 예산, 통근 시간, 필수 조건을 먼저 반영
2. 지표 기반 점수화: 공공데이터 기반 지역별 점수 산출
3. 개인화 가중치 적용: 사용자 선호에 따라 점수 재계산
4. AI 설명 생성: 추천 근거와 주의점을 자연어로 제공

### RAG 구조
- 공공데이터와 파생 지표를 공간 DB에 저장
- 사용자의 질문과 조건을 벡터 검색 및 공간 검색으로 연결
- AI가 검색된 데이터 근거를 바탕으로 추천 결과와 설명을 생성
- 답변에는 가능하면 데이터 출처와 판단 근거를 함께 제시

## 9. 성능 검증 계획

### 정량 검증
- 추천 만족도: 사용자 평가 평균 4.0/5.0 이상
- 추천 수용률: 추천 지역 중 실제 관심 후보로 저장한 비율
- 조건 충족률: 예산, 통근, 필수 조건을 만족하는 추천 비율
- 설명 신뢰도: 추천 이유가 납득된다는 응답 비율
- 응답 시간: 기본 추천 결과 5초 이내 제공

### 정성 검증
- 대전 거주 경험자 인터뷰
- 대전 이주 예정자 사용성 테스트
- 기존 부동산 플랫폼 검색 결과와 비교 평가
- 추천 결과에 대한 전문가 또는 공인중개사 검토

### 비교 실험
사용자에게 동일 조건으로 기존 플랫폼 검색 결과와 본 서비스 추천 결과를 비교하게 한다. 평가 항목은 다음과 같다.
- 내 조건과의 적합성
- 추천 이유의 이해 가능성
- 시간 절약 효과
- 실제 거주 의사
- 신뢰도

## 10. 화면 요구사항

### 온보딩/조건 입력 화면
- 예산, 출근지, 생활 선호를 빠르게 입력
- 슬라이더와 선택형 질문 중심으로 구성
- “교통 우선”, “가성비 우선”, “안전 우선”, “신혼부부형” 등 프리셋 제공

### 추천 결과 화면
- 지도 위 추천 지역 표시
- 추천 지역 TOP 5 카드
- 종합 점수와 세부 점수 표시
- 추천 이유 3가지와 주의점 2가지 제공

### 지역 상세 화면
- 주거비 수준
- 교통 접근성
- 생활SOC 접근성
- 안전/소음/편의 요소
- 개발/정비 이슈
- 비슷한 대안 지역

### 매물 평가 화면
- 사용자가 매물의 주소, 보증금, 월세, 면적, 층수, 옵션을 입력
- AI가 사용자 조건 대비 적합도를 평가
- “추천”, “조건부 추천”, “주의”, “비추천”으로 결과 제공

## 11. 차별점

### 기존 서비스와의 차이
다방, 직방, 네이버부동산 등은 매물 검색과 중개 연결에 초점이 있다. 본 서비스는 사용자의 삶의 조건과 공공데이터를 결합해 소비자 관점에서 좋은 주거 선택을 돕는다.

### 독창성
- 매물 중심이 아니라 사용자 중심 추천
- 집 내부 조건과 외부 생활환경 조건의 통합 평가
- 대전의 도시개발/정비 흐름을 반영한 지역 특화 추천
- 공공데이터 기반 설명 가능한 AI
- 청년/이주민의 지역 정보 비대칭 해소

## 12. 사업화 및 발전 가능성

### 수익 모델
- B2C 프리미엄 주거 리포트
- 공인중개사/임대관리업체 대상 리드 제공
- 지자체 청년주거상담센터 SaaS 제공
- 대학/기업 대상 이주 지원 패키지
- 부동산 플랫폼 API 또는 데이터 분석 제휴

### 확장 전략
- 대전 MVP 이후 세종, 청주, 천안 등 충청권 확장
- 수도권 위성도시 및 지방 광역시 확장
- 청년주거, 신혼부부, 고령자, 외국인 유학생 등 세분화
- 지자체 정책 추천과 연계

### 성장 가능성
지역 공공데이터를 활용해 소비자 중심 주거 추천 모델을 구축하면, 지역별 맞춤 주거 인텔리전스 플랫폼으로 확장할 수 있다. 특히 지방 광역시는 신도시 개발과 원도심 재생이 동시에 진행되는 경우가 많아, 주거 선택 의사결정 도구에 대한 수요가 존재한다.

## 13. ESG 및 사회적 가치

### 사회적 가치
- 청년, 신혼부부, 이주민의 주거 정보격차 해소
- 주거 취약계층의 의사결정 지원
- 허위/과장 매물 정보에 대한 의존도 감소
- 지역 정착 지원

### 환경 가치
- 대중교통 접근성이 높은 주거지 추천을 통해 차량 의존도 감소 유도
- 직주근접 추천으로 통근 거리와 탄소배출 감소 가능

### 거버넌스 및 윤리
- 추천 근거를 설명해 AI 판단의 투명성 확보
- 민감정보 최소 수집
- 특정 지역에 대한 낙인 방지
- 데이터 출처와 업데이트 일자 표시

## 14. 리스크 및 대응

### 리스크 1: 실제 매물 데이터 부족
대응: MVP는 지역/생활권 추천과 사용자 입력 매물 평가를 중심으로 설계한다. 이후 제휴 또는 공개 가능한 매물 데이터 연동으로 확장한다.

### 리스크 2: “살기 좋은 곳” 기준의 주관성
대응: 단일 절대점수가 아니라 사용자 선호 가중치를 반영한 개인화 점수를 제공한다.

### 리스크 3: AI 추천의 신뢰성 부족
대응: 추천 근거, 사용 데이터, 점수 구성 항목을 함께 제공한다.

### 리스크 4: 지역 낙인 가능성
대응: “나쁜 지역”이 아니라 “특정 조건의 사용자에게 맞지 않을 수 있는 조건”으로 설명한다.

### 리스크 5: 데이터 최신성
대응: 데이터별 갱신 주기를 표시하고, 최신성이 중요한 매물 정보는 사용자 입력 또는 제휴 데이터로 보완한다.

## 16. MVP 개발 우선순위

### 1단계: 데이터 기반 지역 추천
- 대전 행정동 단위 데이터 수집
- 주거비, 교통, 생활SOC, 안전, 편의시설 지표 구축
- 사용자 조건 입력 기능
- TOP 5 지역 추천

### 2단계: AI 설명 기능
- 추천 이유 자동 생성
- 주의점 자동 생성
- 사용자 질문 대응 챗봇

### 3단계: 매물 평가 기능
- 사용자가 입력한 매물 조건 평가
- 지역 지표와 매물 내부 조건 결합
- 적합도 리포트 생성

### 4단계: 검증 및 개선
- 사용자 테스트
- 추천 결과 비교 실험
- 가중치 조정
- 발표용 대시보드 및 시연 시나리오 제작

## 17. 심사 기준 대응 전략

### 공공데이터 활용: 30점
전월세 실거래가, 생활SOC, 교통, 안전, 도시개발/정비, 공공시설 데이터를 핵심 추천 로직에 직접 사용한다. 단순 참고자료가 아니라 주거적합도 점수 산출의 필수 입력값으로 설계한다.

### AI 기술 활용: 15점
추천 정확도, 조건 충족률, 사용자 만족도, 설명 신뢰도 등 검증 가능한 지표를 제시한다. 단순 챗봇이 아니라 개인화 추천과 설명 생성에 AI를 활용한다.

### AI 서비스: 15점
AI가 사용자 입력을 해석하고, 추천 후보를 도출하며, 이유와 주의점을 설명한다. 사용자는 복잡한 공공데이터를 직접 해석하지 않아도 된다.

### 독창성: 15점
매물 중개가 아니라 소비자 관점의 주거 의사결정 보조 서비스라는 점을 강조한다. 대전의 개발/정비 흐름을 반영한 지역 특화성이 핵심 차별점이다.

### 발전 가능성: 20점
지자체, 대학, 기업, 공인중개사, 부동산 플랫폼과의 제휴 가능성을 제시한다. 대전에서 검증 후 다른 지방 광역시로 확장할 수 있다.

### ESG 혁신: 5점
청년과 이주민의 정보격차 해소, 대중교통 중심 추천을 통한 탄소저감, 설명 가능한 AI를 통한 윤리적 추천을 강조한다.

## 18. 발표용 핵심 메시지

“대전 맞춤형 주거적합도 AI는 매물을 많이 보여주는 서비스가 아닙니다. 사용자의 삶의 조건과 대전의 공공데이터를 결합해, 어디에 살아야 후회가 적은지 설명해주는 소비자 중심 주거 의사결정 AI입니다.”
